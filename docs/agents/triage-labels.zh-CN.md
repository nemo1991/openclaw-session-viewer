# Triage Labels(triage 标签)

Skills 用五种规范的 triage role 来表达。本文件把这些 role 映射到本仓库 issue 跟踪器实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 的 label | 含义                              |
| ---------------------------- | ----------------------- | --------------------------------- |
| `needs-triage`               | `needs-triage`          | 维护者需要评估此 issue            |
| `needs-info`                 | `needs-info`            | 等待报告者补充信息                |
| `ready-for-agent`            | `ready-for-agent`       | 完整 spec,准备好让 AFK agent 处理 |
| `ready-for-human`            | `ready-for-human`       | 需要人工实现                      |
| `wontfix`                    | `wontfix`               | 不会处理                          |

当 skill 提到某个 role(例如 "apply the AFK-ready triage label"),使用本表右侧对应的 label 字符串。

修改右侧那一列以匹配你实际使用的词汇。
